# Diagrams

← [Docs index](README.md)

`@architect` saves the draw.io diagrams it creates for each track here, named
`<track>-flow.drawio` (for example `disruptions-flow.drawio`), and sometimes
`<track>-sequence.drawio`. The issues it creates link to these files.

- Open `.drawio` files in VS Code with the **Draw.io Integration** extension
  (`hediet.vscode-drawio`, recommended in `.vscode/extensions.json`), or at https://app.diagrams.net.
- The draw.io MCP server is configured in `.vscode/mcp.json` (and `.mcp.json`) as `drawio`.
  Diagram content is sent to the hosted draw.io service, so keep it to architecture and
  synthetic examples.

This folder is intentionally empty in the starter.
